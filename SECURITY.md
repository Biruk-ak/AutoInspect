# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| `main` (latest) | ✅ |
| Older tags | ❌ (best-effort) |

## Reporting a vulnerability

If you discover a security issue in AutoInspect (API, portals, Docker images, or shared packages), please report it privately:

1. Email **birukaklilu0110@gmail.com** with subject `[AutoInspect Security]`
2. Include a clear description, impact assessment, and reproduction steps
3. Do **not** open a public GitHub issue for undisclosed vulnerabilities

We aim to acknowledge reports within **72 hours** and provide a remediation timeline after triage.

## Safe disclosure guidelines

- Avoid accessing other users' data beyond what is required to demonstrate the issue
- Do not run destructive tests against production-like systems you do not own
- Give maintainers reasonable time to patch before public disclosure

Thank you for helping keep AutoInspect and its users safe.
